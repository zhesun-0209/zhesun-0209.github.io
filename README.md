# Zhe Sun's Personal Homepage

Personal academic website of Zhe Sun, built with the [al-folio](https://github.com/alshedivat/al-folio) theme and hosted on GitHub Pages.

## Content

- About: `_pages/about.md`
- Publications: `_bibliography/papers.bib`
- Projects: `_projects/`
- CV: `_data/cv.yml`
- Social profiles: `_data/socials.yml`

Pushes to `main` trigger the included deployment workflow. The generated site is published to the `gh-pages` branch and served at [zhesun-0209.github.io](https://zhesun-0209.github.io).
